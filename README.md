# Bilibili 原帧截图

一款用于 Bilibili 的 Chrome / Edge 浏览器扩展。按下快捷键，即可将视频当前帧以原始分辨率保存为 PNG，无需保留助手标签页。

## 功能

- **提取视频原始帧**：不含网页播放器的进度条、暂停按钮与弹幕覆盖层。
- **自定义快捷键**：通过浏览器原生快捷键管理页面修改。
- **自定义保存文件夹**：选择并授权本地目录，截图直接写入，无需每次另存为。
- **快捷键或按钮截图**：支持视频页快捷键、扩展弹窗和设置页操作。
- **连续截图**：最多同时处理 3 张截图，队列满时明确提示。
- **自动命名**：包含标题、BV 号、分 P 和视频时间，重名自动追加编号。
- **无需常驻标签页**：配置完成后可关闭设置页，扩展自动在后台保存。
- **本地处理**：不需要账号、服务器或本地常驻程序。

## 安装

目前通过开发者模式加载，不需要安装依赖、构建或打包。

1. 下载本仓库 ZIP 并解压，或使用 Git 克隆仓库。
2. 打开浏览器扩展管理页面：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择仓库中的 **`extension` 文件夹**，不要选择仓库根目录。
5. 点击扩展图标，选择“打开截图设置”。
6. 选择本地保存文件夹，并完成浏览器的读写授权。
7. 刷新已打开的 Bilibili 视频页，即可使用。

请保留加载时使用的 `extension` 文件夹。删除或移动该文件夹会影响扩展后续加载。

## 使用

### 快捷键截图

在 Bilibili 普通视频页，将视频暂停到想要的画面，按默认快捷键：

**`Alt + Shift + S`**

播放过程中也可截图。截图对应扩展执行提帧时的当前画面；需要精确选取画面时，建议先暂停。

如果快捷键没有生效，点击扩展弹窗或设置页中的“修改快捷键”，检查实际绑定情况。也可以直接打开：

- Chrome：`chrome://extensions/shortcuts`
- Edge：`edge://extensions/shortcuts`

快捷键仅在浏览器获得焦点时生效。部分组合键可能被系统、浏览器或其他扩展占用。

### 按钮截图

在视频页点击扩展图标，然后点击“保存当前视频帧”。也可以打开设置页，选择一个 Bilibili 视频标签页并截图。

### 更改保存位置

在设置页点击“选择保存文件夹”，重新选择目录并授权即可。配置完成后可以关闭设置页。

浏览器通常只提供文件夹名称，不提供完整绝对路径。若浏览器要求恢复权限，点击“重新授权”；扩展不会自行改存到其他目录。

## 图片格式与命名

输出格式为 **PNG**，尺寸取自当前播放视频流的自然分辨率。例如当前播放 1080p 视频，图片通常为 1920 × 1080；放大浏览器窗口不会提高源视频清晰度。

文件名格式：

```text
标题_BV号_P分集_视频时间_保存时间.png
```

例如：

```text
视频标题_BV1234567890_P2_00-03-25-120_20261108-143015-456.png
```

文件名会清理不适合作为文件名的字符并限制标题长度。已有同名文件不会被覆盖。

网页单独叠加的播放器控件和弹幕不会进入图片；已经录入视频本身的字幕、水印和游戏界面会保留。

## 支持范围与限制

- 面向桌面版 Chrome / Edge，最低 Chromium 版本为 116；其他浏览器未作兼容承诺。
- 仅支持 Bilibili 主站的普通 `/video/` 页面，支持分 P 和全屏播放。
- 暂不支持直播、番剧独立页面、移动浏览器及其他视频网站。
- 最多接受 3 张待处理截图。提示“本次截图未接收”时，请等待队列释放后重试。
- 单张 PNG 上限为 24 MiB，超限时会提示失败。
- 部分跨域或受保护的视频可能无法提帧，扩展不会回退为屏幕区域截图。
- 若合集页面没有更新 URL 中的分 P 参数，文件名中的分集字段可能显示为 P1。
- 保存目录与授权属于当前设备，不会随浏览器账号自动同步。

## 常见问题

**必须保留设置页吗？**

不需要。授权完成后可以关闭所有设置页和扩展弹窗，后台保存由扩展的隐藏文档处理。

**安装或更新后按快捷键没有反应？**

先刷新视频页，再检查扩展是否启用以及快捷键是否已成功绑定。

**提示没有保存权限？**

打开设置页，点击“重新授权”或重新选择文件夹。浏览器重启、权限撤销或目录变化都可能需要恢复授权。

**队列满的提示出现了，但同时还有图片保存成功？**

之前已接受的截图会继续保存；队列满提示对应这一次没有被接受的请求。两种提示会在顶部独立显示。

**可以验证保存失败的提示吗？**

设置页底部提供“故障验证（可选）”。开启模拟后，下一张进入保存步骤的截图会在创建文件前主动失败，随后自动恢复。可再次点击取消；关闭设置页不会取消测试，重新加载扩展会取消。

## 更新

下载或拉取最新代码后，在扩展管理页重新加载扩展，再刷新 Bilibili 视频页。使用原目录更新可保留同一扩展的配置；浏览器要求时重新授权即可。

## 隐私与权限

扩展在本机提取、编码和保存图片，不上传截图，也不需要额外的服务端账号。

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存最近一次截图结果 |
| `offscreen` | 在无可见标签页的隐藏文档中处理与保存图片 |
| `https://www.bilibili.com/*` | 识别视频、获取当前帧并显示操作反馈 |

本地文件夹通过浏览器目录选择器单独授权，目录句柄存储在扩展自己的 IndexedDB 中。扩展不申请其他网站、浏览器历史、Cookie、调试器或桌面捕获权限。
