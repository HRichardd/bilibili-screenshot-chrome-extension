# Bilibili 原帧截图

版本 **0.3.2**。Chrome / Edge 桌面扩展，支持自定义快捷键、自定义本地保存文件夹，无需常驻助手标签页。

## 安装与更新

1. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
2. 加载已解压的扩展程序，选择 **`F:\ai work space\bilibili screenshot\extension`**。
3. 如果原主版本已经从此目录加载，直接重新加载原扩展，不必卸载。确认新增的 offscreen 权限已生效。
4. 点击扩展图标，进入“打开截图设置”，选择保存文件夹并授权。完成后可以关闭设置页。
5. 刷新已经打开的 Bilibili 视频页，按快捷键截图。默认候选为 `Alt+Shift+S`，以浏览器实际绑定结果为准。

此前加载实验目录的用户：停用旧验证版，改用上面的主目录；实验目录已经删除。不同扩展 ID 的目录授权和快捷键相互独立，必要时重新配置。保留原主版本扩展 ID，可以沿用其存储中的目录句柄，权限仍以浏览器为准。

不需要 npm 安装、构建、Playwright、本地常驻程序或服务器。最低要求为支持 Offscreen API 与 runtime.getContexts 的 Chrome / Edge 116+；实际兼容性以浏览器运行结果为准。

## 日常使用

- 在 Bilibili 普通 `/video/` 页面暂停到想要的画面，按快捷键；也可在扩展弹窗点击“保存当前视频帧”。
- 播放中同样可截图，捕获页面执行提帧时的当前画面，不承诺按键物理瞬间的逐帧精度。
- 在弹窗或设置页点击“修改快捷键”，通过浏览器原生管理页修改。快捷键仅在浏览器获得焦点时生效。
- 设置页“选择保存文件夹”用于更改目录，“重新授权”用于恢复失效权限。无需手填绝对路径；界面通常只显示文件夹名称。
- 可以关闭所有设置/助手标签页。隐藏保存文档由扩展自动管理，权限失效时才需要重新打开设置授权。

## 图片与队列

输出 PNG，尺寸等于当前播放视频流的自然尺寸。不会提高源视频画质，也不包含网页播放器进度条、暂停按钮和网页弹幕；视频内嵌字幕、游戏界面和水印保留。

文件名：`标题_BV号_P分集_视频时间_保存时间.png`。标题自动清理非法字符并限制长度，重名追加编号，不覆盖已有截图。网站未更新 URL 的 p 参数时，合集页面的分集字段可能显示 P1。

最多接受三张待处理截图，每张接受后独立提取画面与时间，按顺序写入。队列满时明确提示“本次截图未接收”，可等待后重试。单图上限 24 MiB PNG。

所有提示均在顶部显示：错误保留 7 秒，成功提示排列在错误下方，互不覆盖。只有完整写入并关闭文件流后才报告成功。

## 失败恢复与可选验证

目录权限不足时，打开设置重新授权，不会自动改存默认下载目录。页面未连接扩展时刷新视频页。遇到跨域或受保护视频限制时明确失败，不回退成屏幕区域截图。

设置页底部“故障验证（可选）”可模拟下一次保存失败：下一张进入保存步骤的截图在创建文件前中止，提示明确标注为模拟失败，随后恢复正常。可再次点击取消。关闭设置页不会取消此测试，重新加载扩展会取消。此功能用于验证反馈与恢复，不代表实际磁盘故障测试。

## 项目结构与检查

- `extension/`：唯一可加载的主版本代码。
- `tests/`：提帧、命名、消息边界、后台写入、队列与隐藏文档生命周期的回归测试。
- `ai doc/设计方案.md`：当前设计和验证边界。

在项目目录执行：

```powershell
node --test tests/*.test.mjs
```

当前主版本回归检查为 18 项。测试中的浏览器与文件 API 使用替身；无可见助手截图、重启后截图和看视频约两分钟后再次截图，已由用户在 0.3.1 候选版手动验证。0.3.2 将该实现合并到主目录并整理界面，升级后建议快速确认一次快捷键保存。
